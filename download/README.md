# Download

Download adalah tahap akhir pipeline.

## Pipeline
`mod -> inspect -> asset ditemukan -> export -> ZIP/JSON -> HTTP download`

## Roblox
Web endpoint `/api/assets/roblox/url` menerima URL Roblox resmi dan mengunduh asset melalui Asset Delivery.

## Catatan
File runtime berada di folder generated dan tidak seharusnya dimasukkan ke commit Git.
