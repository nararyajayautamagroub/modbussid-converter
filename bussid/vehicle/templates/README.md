# BUSSID Vehicle Templates

Template asset BUSSID dipisahkan menjadi tiga kategori:

- **AO**: Ambient Occlusion.
- **Texture**: texture kendaraan umum.
- **XOR**: template kaca/window.

## Alur
Inspector menemukan texture -> classifier menentukan template -> user memilih AO/Texture/XOR -> export -> download.

Classifier menggunakan nama file sebagai heuristik, jadi hasil tetap perlu diperiksa jika penamaan asset tidak jelas.
