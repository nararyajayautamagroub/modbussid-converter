# BUSSID Lights

Animasi lampu dipisahkan agar dapat dikelola sebagai asset sendiri.

## Preset
- **Strobo**: pulsa ON/OFF cepat.
- **Rotator**: phase 0/90/180/270.
- **LED Bar**: intensitas naik-turun.

## Export
`bussid/lights/export.py` menghasilkan paket data animasi. Ini adalah interchange package, bukan format internal BUSSID native.
