# ETS2 Vehicle

Adapter inspeksi/export kendaraan ETS2.

## Ekstensi yang dikenali
`.scs`, `.sii`, `.sui`, `.pmd`, `.pmg`, `.pma`, `.pmc`, `.ppd`, `.pip`, `.mat`, `.dds`.

## Fitur
Metadata, hash, archive listing, dan export ZIP + manifest.

## Penting
File SCS engine seperti PMD/PMG tidak otomatis berubah menjadi OBJ/FBX hanya karena diexport. Native geometry conversion membutuhkan parser/toolchain yang memahami format tersebut.
