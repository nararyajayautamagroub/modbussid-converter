# Folder Descriptions

| Folder | Purpose |
|---|---|
| `backend` | FastAPI API, auth, scraper, catalog, gateway, and asset routes. |
| `frontend` | Responsive website and PWA shell. |
| `core` | Shared business/domain logic. |
| `platforms` | BUSSID, ETS2/ATS, and Roblox adapters. |
| `assets` | Templates and project asset inputs. |
| `artifacts` | Runtime generated output. |
| `tooling` | CLI, smoke tests, frontend test, and repository audit. |
| `tests` | Automated regression suite. |
| `docs` | Architecture and migration documentation. |

The live endpoint `GET /api/repository/folders` exposes the same descriptions as JSON so the website can display them.
