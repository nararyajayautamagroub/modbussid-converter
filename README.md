# Game Mod Asset Lab

Web toolkit with separate categories for BUSSID Vehicle, BUSSID Map, BUSSID Kodename, BUSSID Sprite Sheet, ETS2 Vehicle, and ETS2 Map.

Protected/encrypted content is detected and reported, not bypassed.

Run: `python -m pip install -r requirements.txt` then `python -m uvicorn web.app:app --host 127.0.0.1 --port 8000`.
