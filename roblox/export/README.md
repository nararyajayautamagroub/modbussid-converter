# Roblox Export

Tempat adapter output Roblox.

## URL asset
`url_asset.py` menerima URL resmi Roblox, mengambil Asset ID, meminta asset melalui Asset Delivery resmi, lalu menginspeksi hasilnya.

## Alur
URL -> validasi domain -> Asset ID -> download -> inspect -> download hasil.

## Batas
Tidak dapat mengakses asset privat yang tidak diberikan akses. Tidak ada bypass permission.
